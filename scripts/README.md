# Scripts

Yardımcı script'ler buraya konur (ör. müzik indirme). Müzik ve ses dosyaları repoya commit'lenmez.

Müzik indirme: `backend` klasöründe `python -m app.music.download` çalıştırın (`--target`, `--candidates`, `--dry-run`); çıktı `data/music/` altına yazılır, `.env` içinde `JAMENDO_CLIENT_ID` gerekir.
